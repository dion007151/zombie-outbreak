# Zombie Outbreak

A browser-playable zombie school survival game built with HTML Canvas.

Made by Dionimar Flores.

## Play Locally

Open `index.html` through a local static server, then press **Start**.

Controls:
- `WASD` to move
- Mouse to look
- Click to shoot
- `Esc` to pause to the menu
- `C` to continue from the menu

## Deploy

This project is ready for Vercel as a static site. The intended production name is `zombie-outbreak`.
